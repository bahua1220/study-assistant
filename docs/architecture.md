# 架构与数据边界

## 客户端

React / TypeScript 页面运行于浏览器或 Capacitor Android WebView。页面按路由懒加载；词汇列表按页读取，单词本关系保存在词卡上，多个本子不复制同一词卡的 FSRS 记忆。

Dexie 封装 IndexedDB：计划、轮次、作答、词卡、复习日志和其他学习记录使用 ownerId 隔离。轮次保存题目顺序、题型和位置，不依赖组件内存续学。

作答写入使用单一事务处理作答证据、FSRS 更新和进度；事务失败全部回滚。统计基于原始作答，不以 FSRS lapses 冒充实际答错次数。

删除学习计划会结束其未完成轮次，但保留词卡和历史。重新创建使用新 ID；恢复旧计划前检查同书是否已有当前计划，防止覆盖或产生两个有效计划。

Android 自定义插件负责本地英文朗读与屏幕固定尝试。应用不能保证锁住用户系统，也不能保证每台设备预装英文语音包。

## 后端

FastAPI 提供注册登录、词库检索、备份、识图和答疑等接口。用户及云端文本数据保存于 SQLite。密码使用 PBKDF2 哈希，API 使用 JWT 鉴权；部署时仍需独立完成 TLS、网络与运行环境保护。

词汇入库流程为：图片识别或手动文本 → 规范化与人工校正 → 批量词库检索 → 缺失条目模型兜底 → 客户端确认保存。不是向量检索，也不是 RAG。

图片答疑先保存任务并返回 taskId，客户端查询状态。任务为进程内 asyncio 任务，SQLite 保存状态和结果；不宣称具备消息队列、分布式容错或高并发服务能力。

云备份导出当前账号的数据并恢复关联 ID；图片 Blob 不包含在文本备份中。恢复会替换当前账号的数据，操作前应备份，并明确告知使用者。

## 仓库与部署配置

仓库是独立、脱敏的源码快照，不包含原工作区历史、部署工具、服务端域名或现有运行数据库。

模型选择、接口地址、密钥和供应商扩展参数必须由使用者在本地环境变量中配置。历史 QWEN_* 字段只是兼容接口名，不包含实际部署选择。VISION_REQUEST_OPTIONS_JSON 默认为空对象；只有在自己的供应商文档要求时才填入扩展参数，不允许覆盖 model/messages/鉴权字段。

现有作者 App、服务器与真实数据不会被此展示仓库的配置更改。
